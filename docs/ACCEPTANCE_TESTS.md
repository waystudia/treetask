# Критерии приёмки

## Прогресс дерева

- Веса 1/2/3/5/8/13 и проценты задач рассчитываются детерминированно.
- Binary, checklist и manual дают ожидаемые значения на границах 0 и 100.
- Без результатов общий процент равен задачам; с результатами — 70/30.
- Submitted без evidence равен 0; с evidence — 50; confirmed — 100.
- Стадия ствола/кроны зависит только от task progress; изменение результатов
  меняет outcome layer, но не стадию дерева.
- Стадия дерева ограничена 00–20, outcome layer — 00–05.

## Доступ и данные

- Анонимный пользователь не читает private rows/buckets.
- Участник одного проекта не читает/изменяет другой проект.
- Update не может переназначить чужой `project_id`/`created_by`.
- Клиентский bundle не содержит server-only secrets.
- Offline mutation переживает reload и отправляется ровно один раз.
- Remote pull не перезаписывает локальную pending mutation; private Broadcast
  доступен только участнику соответствующего project topic.
- Созданный offline проект доступен в форме задачи; загруженный файл остаётся
  после reload и для UUID-проекта попадает в закрытый Storage.

## Canvas и фото

- Zoom не выходит за 5–800%; pinch сохраняет точку под пальцами.
- На Mac мышь/трекпад рисует только при физически удерживаемой основной кнопке;
  простое движение курсора не создаёт stroke.
- При выборе кисти видны ширина, жёсткость, цвет и настройка pressure. Для пера
  используется доступное `PointerEvent.pressure`, для мыши — безопасная имитация.
- Удержание в конце штриха 1–2 секунды запускает распознавание линии, стрелки,
  круга, эллипса, квадрата, прямоугольника, треугольника или ромба.
- Undo возвращает исходный stroke после автокоррекции фигуры.
- Каракуля с confidence ниже 0.82 не превращается в фигуру.
- Аннотации не меняют хэш исходного изображения.
- Export PNG/PDF визуально содержит выбранные annotations.
- Карточки задач, подпроектов и файлов Canvas сохраняют id доменной записи и
  показывают её актуальные название, срок/вес или прогресс.

## UI и качество

- Нет горизонтального overflow на 390, 768 и 1440 px.
- Основные действия доступны с клавиатуры и имеют accessible name.
- Loading/error/empty/offline состояния проверены.
- `pnpm lint`, `typecheck`, `test`, `test:db`, `test:e2e`, `build` зелёные.
- Browser console не содержит ошибок на ключевых маршрутах.
